# Gemma 4 Modelfiles

This repository contains a collection of custom Modelfiles for various configurations of the Gemma 4 model family, designed to be used with Ollama.

Modelfiles allow users to bake specific parameters, system prompts, and context window sizes directly into a model, ensuring consistent behavior across different sessions.

## 🚀 Models Included

This repository currently contains Modelfiles for the following specialized versions:

*   **`gemma4-claude.modelfile`**: The primary, general-purpose agentic configuration for Gemma 4, optimized for structured tool use and coding tasks within an agentic workflow.
*   **`claude-planner-gemma4.modelfile`**: A specialized planner configuration, likely tuned for multi-step reasoning and architectural design.
*   **`specs-reader.modelfile`**: A model variant focused on reading and interpreting technical specifications.

## 🛠️ Setup and Usage

To use these models, ensure you have [Ollama](https://ollama.com/) installed and running.

1.  **Pull the Model:** Use the `ollama create` command for each model you wish to use.

    ```bash
    # Example for the main agent model
    ollama create gemma4-claude -f ./gemma4-claude.modelfile
    ```

2.  **Run the Model:** Once created, you can run the model interactively:

    ```bash
    ollama run gemma4-claude
    ```

## ⚙️ Modelfile Customization

Each Modelfile contains specific parameters (`PARAMETER`) and a system prompt (`SYSTEM`) to guide the model's behavior.

*   **`SYSTEM` Prompt**: Defines the core persona and rules (e.g., "You are a senior software engineer operating as a coding agent.").
*   **`PARAMETER`**: Sets global generation parameters like `temperature`, `num_ctx`, `top_p`, etc., to enforce consistent performance for agentic tasks.
